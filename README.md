## 🛠️ The Workflow Mapping Framework (`Worksheet_Map_Your_Workflow.docx`)

Located in the main directory, the **Workflow Mapping Worksheet** provides a practical framework for identifying and executing high-impact AI automation opportunities across personal or organizational duties.

### **How to Use the Framework**:

1. **Establish Core Objectives**: Define top-level professional or project goals.
2. **Itemize Operational Duties**: Break down monthly objectives into specific, granular tasks.
3. **Task Assessment Criteria**: Evaluate each duty across three key metrics:
  * **Duration**: Total hours spent per execution.
  * **Frequency**: How often the task repeats (daily, weekly, monthly).
  * **Uniformity / Repetitiveness**: Degree of standardization and rule-based consistency.
4. **Identify AI Automation Candidates**: High-duration, high-frequency, and highly uniform tasks are prioritized for AI tool assistance, custom prompt chaining, or dedicated app building.

## ⚡ Real-World Capstone Implementation

The learnings compiled in this repository were put into practice through a full capstone application: **Visual Artist AI Studio** https://visual-artist.ai.studio/

### **Application Highlights**:

* **Deterministic In-Browser ML**: Computes Ordinary Least Squares (OLS), Ridge/Lasso penalties, Logistic Sigmoid, and Lloyd's K-Means directly in browser JavaScript with single-digit millisecond latency—avoiding LLM calculation hallucinations.
* **Target-Conditioned Modeling Engine**: Automatically detects whether a target variable is continuous or discrete, dynamically adjusting downstream machine learning algorithms and diagnostic charts.
* **Auto Data Profiler &amp; Interactive Cleaning**: Audits column types, missingness, skewness, IQR, and outlier indices, providing interactive imputation (Mean/Median/Mode), feature scaling, and one-hot encoding with a full undo trail.
* **Dual-Language Code Studio**: Translates every GUI interaction and data transformation live into production-ready **Python (** **scikit-learn** **)** and **R (** **tidyverse** **)** code blocks.
